# Contributing to Developer Certification Handbook

Thank you for your interest in contributing to the **Developer Certification Handbook**!

This project is a community-driven, open-source guide maintained alongside [careers.codes](https://www.careers.codes) to help software engineers, DevOps practitioners, cloud architects, and security professionals choose, prepare for, and pass top industry certifications.

## How Can You Contribute?

1. **Update Exam Details:** Keep exam codes, fees, passing criteria, and domain weights updated.
2. **Add Study Notes & Architectures:** Contribute architectural diagrams, hands-on lab tips, and cheat sheets.
3. **Refine Screening Scenarios:** Add real-world screening interview questions asked about specific certifications.
4. **Fix Typos & Dead Links:** Spot errors, broken links, or outdated exam retirements.

## Pull Request Guidelines

1. **Fork the Repository:** Create a personal fork on GitHub.
2. **Create a Feature Branch:** \git checkout -b update/cka-exam-tips\
3. **Make Atomic Changes:** Keep edits focused on specific certification guides.
4. **Follow Markdown Conventions:**
   - Preserve clean table formatting
   - Keep code and command snippets tested and valid
5. **Submit a Pull Request:** Explain the rationale behind your additions or updates.

Thank you for helping developers advance their tech careers worldwide!
