## 1. Google UX Design Framework & Screening Scope

The Google UX Design Certificate validates practical expertise in user-centered design, user research, wireframing, prototyping, usability testing, and accessibility.

1. **Empathize:** Conduct user research, interviews, create Personas and Empathy Maps.
2. **Define:** Synthesize user pain points into clear "How Might We" (HMW) Problem Statements.
3. **Ideate:** Brainstorm design concepts using Crazy Eights and Information Architecture (IA).
4. **Prototype:** Create Low-Fidelity paper wireframes and High-Fidelity interactive Figma prototypes.
5. **Test:** Conduct usability studies, measure System Usability Scale (SUS), iterate designs.

## 2. User Research & Problem Statement Framing (HMW)

**Interview Scenario:** *"How do you translate raw user interview transcripts into actionable User Personas and Problem Statements?"*

* **Empathy Mapping:** Categorize qualitative feedback into 4 quadrants: What the user **Says**, **Thinks**, **Does**, and **Feels**.
* **User Personas:** Build realistic user archetypes representing target audience demographics, goals, behaviors, and core frustration pain points.
* **Problem Statements (HMW):** Frame problem statements around user needs:
  *Example:* *"How might we help busy working parents order healthy meals in under 3 clicks so they can save time on weeknights?"*

## 3. Wireframing, Information Architecture, & Figma Prototyping

**Interview Scenario:** *"Walk me through your transition from paper wireframes to a high-fidelity interactive prototype in Figma."*

* **Information Architecture (IA):** Organize page hierarchies and user flow paths using card sorting exercises.
* **Low-Fidelity Wireframes:** Focus on layout structure, content hierarchy, and navigation flow without visual styling (colors, images, fonts).
* **Figma High-Fidelity Components:** Build reusable UI design tokens (color variables, typography scale), Auto-Layout for responsive resizing, component variants, and interactive prototype transitions (Smart Animate).

## 4. Usability Testing & Iterative Design Cycles

**Interview Scenario:** *"How do you structure an unmoderated usability study, and how do you handle negative user feedback?"*

1. **Study Plan & Prompt Cards:** Write neutral, task-based scenario prompts without leading questions (e.g., *"Find a flight from Lahore to Dubai on Friday and complete checkout"*).
2. **Affinity Diagramming:** Group usability testing observations into patterns: Navigation confusion, copy clarity, visual hierarchy.
3. **Design Iteration:** Prioritize fixes addressing Critical Usability Blockers before polishing minor aesthetic details.

## 5. Web Accessibility Standards (WCAG 2.1 AA) & Design Systems

**Interview Scenario:** *"How do you ensure your product design passes WCAG 2.1 AA accessibility compliance?"*

* **Color Contrast Ratios:** Ensure text meets minimum contrast ratio thresholds against background colors:
  - Normal Text: Minimum **4.5:1** contrast ratio.
  - Large Text (18pt+ / 14pt bold): Minimum **3:1** contrast ratio.
* **Non-Text Indicators:** Never rely solely on color to convey state (e.g. add error icons alongside red text for colorblind accessibility).
* **Keyboard Navigation & Screen Readers:** Include clear focus indicator rings and aria-labels for screen reader parsing.
